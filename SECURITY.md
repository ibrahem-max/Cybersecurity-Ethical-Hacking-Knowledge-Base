# Security Policy

## Scope
This repository is educational reference material, not a product that provides a security boundary.

## Reporting a concern
Do not publish secrets, personal data, or exploitable details about a real third-party system in an issue. For issues relating to this repository's content, open an issue with a concise description and a safe reproduction using a local training environment.

## Safe use
Only test systems you own or are explicitly authorized to assess. Never submit actual credentials, tokens, private IP inventories, or confidential logs to this repository.

## Supported content
We welcome corrections to defensive guidance, dead links, inaccurate citations, and updates to official standards.
