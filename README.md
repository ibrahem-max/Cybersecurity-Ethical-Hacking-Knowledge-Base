## العربية

### هدف المشروع
جمع مسارات التعلّم والمفاهيم الأساسية والأدوات والمراجع العملية للأمن السيبراني والاختبار الأمني الأخلاقي في مستودع واحد قابل للتطوير. لا توجد قاعدة معرفة واحدة يمكنها تضمين «كل شيء»؛ لذلك ينظم هذا المشروع الموضوعات الأساسية ويربطها بمراجع رسمية يتم تحديثها باستمرار.

### ابدأ من هنا
1. **[خارطة التعلّم](docs/learning-roadmap.md)** — مراحل مقترحة من الأساسيات حتى الاختبار الأمني.
2. **[أساسيات الشبكات](docs/networking.md)** — TCP/IP وDNS وHTTP وTLS والمنافذ.
3. **[أمن الويب](docs/web-security.md)** — مفاهيم OWASP Top 10 وطرق الوقاية.
4. **[أمن الأنظمة](docs/endpoint-security.md)** — Linux وWindows والتقوية والسجلات.
5. **[التشفير](docs/cryptography.md)** — التجزئة والتشفير والتوقيعات وإدارة المفاتيح.
6. **[الاختبار الأخلاقي](docs/ethical-testing.md)** — النطاق والتصريح والمنهجية والتقرير.
7. **[الأدوات والمختبرات](docs/tools-and-labs.md)** — أدوات دفاعية وبيئات تدريب قانونية.
8. **[الاستجابة للحوادث](docs/incident-response.md)** — التحضير والكشف والاحتواء والتعافي.
9. **[المراجع](docs/resources.md)** — مصادر موثوقة وشهادات ومنصات تدريب.
10. **[مسرد المصطلحات](docs/glossary.md)** — مفردات عربية/إنجليزية.

### المبدأ الأساسي
اختبر الأنظمة التي تملكها أو لديك تفويض مكتوب لاختبارها فقط. لا تستخدم المعلومات أو الأدوات للوصول غير المصرح به، أو سرقة البيانات، أو تعطيل الخدمات، أو تجاوز أنظمة الحماية. اتبع قوانين بلدك وشروط المنصات، وفضّل المختبرات التعليمية المعزولة.

### المساهمة

## English

A bilingual, evolving knowledge base for cybersecurity, defensive security, and authorized ethical testing. No single repository can literally contain every cybersecurity topic, so this project curates core concepts and points learners to maintained primary sources.

Start with the learning roadmap, then explore networking, web security, endpoint hardening, cryptography, authorized testing methodology, tools and labs, incident response, trusted resources, and the glossary.

**Responsible use:** Test only systems you own or are explicitly authorized to assess. Do not use these materials for unauthorized access, data theft, disruption, or evasion. Use isolated training labs and follow applicable laws.

Contributions should be source-backed, clearly scoped, and safety-conscious.
